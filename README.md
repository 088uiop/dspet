# 大肥鱼桌宠 · dspet 🐋

一只住在 Windows 桌面上的透明桌宠：三视图动画、自由散步、能换衣服、能按部位摸、能聊天。

**拿到就能跑，不依赖任何后端。** 不配 API 也有完整的宠物体验（自己走路、自己念叨、被摸会回嘴）；想让她会聊天，填一个 OpenAI 兼容接口的 Key 就行。

## 与原版的区别

| | 上游 dafeiyu-pet | 本版 dspet |
|---|---|---|
| 聊天 | 直连 DeepSeek，Key 存 `config.json` | **任意 OpenAI 兼容接口**（DeepSeek / Ollama / LM Studio / 自建），菜单里可视化配置 |
| 台词 | 硬编码在 `桌宠.py` 里的 `LINES` 列表 | **外部化成 `lines.json`**，按用途分组，换角色不用改代码 |
| 换衣服 | 无 | **一套衣服 = 一个文件夹**，右键菜单直接切，存的名字失效自动回落 |
| 点它 | 单击蹦跳回嘴 / 双击喂食 | **双击按部位摸**：部位名和区域都由 `config.json` 自定义，每个部位一套反应 |
| 部位怎么分 | 写死在代码里的比例 | **每套衣服一份 `config.json`**，想分几块分几块；数组顺序决定重叠时的优先级 |
| 依赖后端 | 部分版本需要外部 AI 服务 | **零后端**，缺 Key 只是不能聊天，其他功能全部正常 |
| 喂食 / 天气 / 自启 | 有 | 移除（喂食面板、`wttr.in`、注册表自启都删了，少一堆失败路径） |
| 语音 | 无 | 无（想加可以自己做 TTS，见 FAQ） |
| 托盘菜单 | 有 | 有，并修掉 Windows 上「菜单项要点两次才生效」的老毛病 |
| 单实例 | 无 | `QLockFile` 锁：开第二只会自己退出，避免一句台词两边同时弹 |
| 尺寸 | 运行时缩放 | 三档预渲染（187 / 238 / 306），并修掉 `int(0.7*340)=237` 导致中号一直缩放的问题 |
| 装新形象的流程 | 两个脚本、路径写死在代码里 | **一条命令** `make_sprites.py`，参数化，还能顺手画部位示意图 |

### 部位区域划分（差异化最大的一处）

这是「按部位摸」和「一图多反应」的基础，也是上游完全没有的东西。

**坐标是比例，不是像素。** 相对的是**那一张精灵图的外框**（抠干净、统一高 340 之后的那张），左上角 `(0,0)`，右下角 `(1,1)`。所以同一份比例在大中小三档、在正面/侧面/背面三种视角下都成立，不用按像素重算。

每套衣服目录下的 `config.json`，**最外层是数组**，一个元素就是一个部位：

```json
[
  {
    "name": "头部",
    "rects": [ { "x": { "min": 0.05, "max": 0.92 }, "y": { "min": 0.04, "max": 0.55 } } ]
  },
  {
    "name": "尾巴",
    "rects": [ { "x": { "min": 0.51, "max": 0.95 }, "y": { "min": 0.71, "max": 0.89 } } ]
  },
  {
    "name": "手臂",
    "rects": [
      { "x": { "min": 0.12, "max": 0.37 }, "y": { "min": 0.58, "max": 0.79 } },
      { "x": { "min": 0.57, "max": 0.80 }, "y": { "min": 0.59, "max": 0.77 } }
    ]
  },
  {
    "name": "胸部",
    "rects": [ { "x": { "min": 0.36, "max": 0.60 }, "y": { "min": 0.56, "max": 0.68 } } ]
  }
]
```

规则只有四条：

1. **部位名随便起**，不再是固定的六个。`name` 写什么，摸到这里就报什么名字；想给某个部位配专属台词，就在 `lines.json` 的 `touch` 里用同名 key（没配台词就播报「你摸到我的××了」）。
2. **`rects` 是一个数组**，一个部位可以有多块区域（比如左右手臂各框一次），点中任意一块都算这个部位。
3. **`x`、`y` 都是相对比例**，相对的是**那一张精灵图的外框**（抠干净、统一高 340 之后的那张），左上角 `(0,0)`，右下角 `(1,1)`；`min`/`max` 写反了会自动纠正。
4. **数组顺序就是优先级，越靠上的越优先**。两块区域重叠时算排在前面的那个——比如「手臂」排在「尾巴」前面，重叠的那一片就归手臂；想反过来，就把「尾巴」整段挪到前面（标注工具里拖动部位名即可）。

没写 `config.json` 时，程序会用内置的 `DEFAULT_ZONES`（默认部位名：`头部` `胸部` `手臂` `腿脚` `尾巴` `肚子`）。所以：

- 换一张**构图接近**的图 → 不用改区域，直接能摸；
- 换了**构图差别大**的图（比如换成长条形的猫、脑袋特别大的体型）→ 一定要重标，否则点哪儿都是同一块。

> 旧版 `config.json`（最外层是字典、键名固定）已经不再读取：遇到字典格式会打印一条提示并退回内置分区，用下面的标注工具重新导出一次数组格式就好。

标定不用盲猜：`python make_sprites.py <三视图目录> --preview` 会生成一张 `zones-preview.png`，把 `config.json` 里的部位框（带部位名）画在正面图上，照着改比例即可。

每个部位的台词在 `lines.json` 的 `touch` 里，改词不用碰代码。

## 快速开始

需要 **Windows + Python 3.11+**（用了 Win32 窗口样式与托盘，没做跨平台适配）。

```bash
git clone https://github.com/088uiop/dspet.git
cd dspet
pip install -r requirements.txt
pythonw dspet.py
```

或者双击 `启动桌宠.bat`（会优先用 `%LOCALAPPDATA%\Programs\Python\Python312\pythonw.exe`，找不到就用 PATH 里的 `pythonw`）。

首次运行会在目录下生成两个文件：`config.json`（你的设置）和 `lines.json`（台词库），都已加进 `.gitignore` / 可自由改。

**不配 API 也能玩**：她自己散步、偶尔自言自语、被摸会回嘴。想要聊天，右键 →「聊天设置」填接口地址、模型、Key。

## 会什么

- **三视图行走**：左右走用侧面（自动镜像）、向上走用背面、向下走用正面，带加减速惯性和转向交叉淡化
- **三种模式**：自由散步 / 跟随鼠标 / 原地待着
- **三档尺寸**：小 / 中 / 大，都有预渲染副本，不糊
- **换衣服**：右键菜单切换，`sprites/clothes/` 下一个文件夹一套
- **按部位摸**：双击身体，部位名和区域都写在衣服的 `config.json` 里，想分几块分几块（台词可改）
- **聊天**：单击鱼身弹输入框，接你配的 API，保留最近 N 条上下文
- **进出屏幕**：走出去藏起来，再从边缘走回来，不是瞬移
- **气泡**：自动换行、按文字量撑高、内心戏用灰色斜体加括号
- **系统提醒**：CPU > 90%、内存 > 95%、N 卡温度 > 80°C 时冒个泡
- **桌面友好**：无边框透明、窗口置顶、鼠标穿透（穿透后从托盘解除）、拖动换位置、记住上次位置

## 换成你自己的形象

### 1. 准备三视图

白底的 正面 / 侧面 / 背面 三张 PNG，人物居中、别贴边。**三张要同一高度、同一比例**（侧面和背面按同一身高画，程序会统一缩放到 340px）。

### 2. 一条命令做成一整套

```bash
pip install pillow
python make_sprites.py 我的立绘            # 输出到 sprites/clothes/我的立绘/
python make_sprites.py 我的立绘 --preview  # 顺便画一张部位区域示意图
python make_sprites.py 我的立绘 --icon     # 顺便更新托盘图标
```

它会做完这些事：白底泛洪抠图 → 边缘去白混合（消白边）→ 统一高 340 → 预乘 alpha 缩放出 `_187 / _238 / _306` 三档 → 没有 `config.json` 就写一份部位模板。

### 3. 标部位

推荐用配套的网页工具 **[image-part-annotator](https://github.com/088uiop/image-part-annotator)**（单 HTML 文件，双击就能用）：

1. 打开工具，载入 `sprites/clothes/我的立绘/正面.png`（**注意是处理过的这张**，比例相对它才算得准）
2. 添加部位名：**随便起**（`头部` `手臂` `尾巴`……都行）。想沿用内置台词的话，就用 `头部` `胸部` `肚子` `手臂` `腿脚` `尾巴` 这几个名字
3. 在图上拖拽框选；同一部位框多次（左右手各框一次），导出的 `rects` 自动是数组
4. 按住部位左侧 `⠿` 拖动排序——**越靠上的部位越优先**，重叠区域归排在前面的那个
5. 右下角下载 `config.json`，放进 `sprites/clothes/我的立绘/` 覆盖模板
6. 导出的 JSON 也可以再「导入」回工具里继续改

不想开浏览器也行：`--preview` 生成的 `zones-preview.png` 会把 `config.json` 里的部位框画在图上，照着改比例再复查。**部位区域别互相压太多**，实在要压就靠数组顺序定优先级（见上面「部位区域划分」）。

### 4. 切过去

右键 →「换衣服」→ 选你的那套。首次没选过的话，程序默认找 `女仆装`，找不到就用目录里第一套。

## 聊天接口怎么配

右键 →「聊天设置」，三个字段：

| 字段 | 例子 | 说明 |
|---|---|---|
| 接口地址 | `https://api.deepseek.com/v1` | 填到 `/v1` 即可；也可以直接填完整的 `/chat/completions` |
| 模型 | `deepseek-chat` | 接口那边支持什么就填什么 |
| API Key | `sk-...` | 留空 = 只用台词，不聊天 |
| 人格设定 | 一句话 | 作为 system prompt，决定她怎么说话 |

常见搭配：

```text
DeepSeek     https://api.deepseek.com/v1            deepseek-chat
Ollama       http://127.0.0.1:11434/v1              qwen2.5:7b        （Key 随便填，比如 ollama）
LM Studio    http://127.0.0.1:1234/v1               local-model
```

Key 存在 `config.json` 里，这个文件不进版本库。

## 台词库 `lines.json`

```json
{
  "idle":  ["没人理她时自己念叨的话"],
  "inner": ["内心戏，显示成灰色斜体（……）"],
  "drag":  ["被拖动、放下来时说的"],
  "touch": {
    "头部":  ["摸头"],
    "胸部": ["摸胸"],
    "肚子": ["摸肚子"],
    "手臂": ["摸手"],
    "腿脚": ["摸脚"],
    "尾巴": ["摸尾巴"]
  },
  "no_api": ["点聊天但没配 Key 时说的"]
}
```

- 每个分类一个数组，随机抽一条
- `touch` 的 key 就是衣服 `config.json` 里的部位 `name`，**名字对上才有专属台词**；没对上的部位统一播报「你摸到我的××了」
- 部位名是你自己起的，所以 `touch` 里也可以加任意新 key（比如 `"左手": [...]`）
- 缺的分类会自动用内置默认值补上，**删掉某个键也不会崩**
- 右键「爱说话」可以关掉自言自语（只关 `idle` 和 `inner`，摸头/拖动照旧）

## 配置文件 `config.json`

注意区分两份同名文件：**根目录这份是程序设置**（下面这些键），**衣服目录里那份是部位区域**（见上面「部位区域划分」）。

| 键 | 说明 |
|---|---|
| `mode` | `wander` / `follow` / `still` |
| `size` | `0.55` / `0.7` / `0.9` |
| `x` / `y` | 上次的位置 |
| `outfit` | 当前衣服（文件夹名） |
| `topmost` / `passthrough` | 置顶 / 鼠标穿透，重启后恢复 |
| `idle_talk` | 要不要自言自语 |
| `ai` | `{base_url, model, api_key, system_prompt, max_history}` |

## 打包成 exe

```bash
pip install pyinstaller

```

产物在 `dist/`（`sprites/` 与 `lines.json` 都会打进去）。杀毒软件对 PyInstaller 产物误报是常事，加信任即可。

## FAQ

- **双击没反应 / 摸哪都一样**：那套衣服的 `config.json` 没标好、还是旧版字典格式，或者区域没覆盖到身体。用 [image-part-annotator](https://github.com/088uiop/image-part-annotator) 重新框一遍并导出数组格式（记得框在处理过的 `正面.png` 上），或者 `--preview` 看图再改。
- **点了聊天框不回复**：菜单「聊天设置」里 Key 是不是空的；或者接口地址填错了（本地模型要确认服务真的在跑）。气泡会直接说原因：`Key 不对` / `连不上接口：…`。
- **`ModuleNotFoundError: psutil`**：`pip install -r requirements.txt`；如果你用的是 `pythonw`，确认装的是同一个解释器的包。
- **托盘菜单点了没反应**：本版已修（菜单只挂一次，弹出前 `aboutToShow` 原地重填）。改代码时别在 `activated` 里 `setContextMenu`，那正是「要点两次」的根源。
- **想知道她在哪**：找不到窗口时，右键托盘 →「回到屏幕内」。
- **想加语音**：`lines.json` 是纯文本，没有音频字段；要念出来得自己做 TTS 然后在 `say()` 里接一手播放。
- **非 Windows**：窗口穿透、托盘菜单都用了 Win32 API，别指望直接跑。
